BactoMate Custom — source installation
======================================

Use branch BactoMate_Custom_New-Analyses from:
https://github.com/santinlab-code/BactoMate

Branch ZIP:
https://github.com/santinlab-code/BactoMate/archive/refs/heads/BactoMate_Custom_New-Analyses.zip

Extract the entire source folder. Use Python 3.11. Upstream release apps may not
contain this custom code; install from this branch or use a build made from it.

macOS (Terminal in the folder containing main.py):
  chmod +x setup/macos/*.sh launch_gui.sh
  ./setup/macos/install.sh
  ./launch_gui.sh

Windows (64-bit Python 3.11, Command Prompt in the project folder):
  setup\windows\install.bat
  launch_windows.bat

Create the venv at its final path. Recreate it after moving or replacing the
project; do not copy the old venv into a new ZIP folder.

Current features: MODIFICATIONS_BACTOMATE_EN.md (also available in French)
